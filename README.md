# Трекер питания (все файлы в одной папке)
- index.html — приложение; tracker_pitaniya.py + dishes_data.py — консольная версия.
- desktop_app.py, build_exe.bat — сборка Windows .exe (или через GitHub Actions).
- build.yml — файл автосборки .exe и .apk. На GitHub его нужно создать по пути .github/workflows/build.yml.
